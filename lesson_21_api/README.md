## Overview
Цей Computer Vision дозволяє користувачам завантажувати будь-які зображення через HTTP POST-запит і миттєво отримувати результати класифікації у зручному JSON

- FastAPI 
- Uvicorn 
- `http://127.0.0.1:8000` хостинг, лок адрес
- `http://127.0.0.1:8000/docs` (Swagger UI), дозволяє тестувати сервіс з браузера.

## Для запуску проєкту локально виконайте наступні кроки у вашому терміналі:

1. Клонувати або створити папку з проєктом
   ```bash
   cd path/to/project
2. Встановити усі необхідні залежності
   pip install -r requirements.txt
3. Запустити веб-сервер
   python -m uvicorn app:app --reload


## Modeling info
google/vit-base-patch16-224 (Vision Transformer).

Архітектура: замість CNN тут модель Transformer адаптований для аналізу зображень.
Завантажуєтьсяз Hugging Face за допомогою pipeline

## Interface description
endpoint

GET /
Перевірка працездатності сервера

Вхі-немає параметрів.
Вихід-JSON-об'єкт з повідомленням про статус.

POST /predict
Головний ендпоінт для класифікації зображень.

Вхід-Файл зображення(передається через параметр file.
Вихід-JSON-об'єкт де є ім'я файлу та масив predictions із 5 найімовірніших класів об'єктів та їх рівнем ймовірності
